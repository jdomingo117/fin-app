# Console Phase 5 owner fixes

25–26 November 2026. This record covers the original owner review and the pre-merge follow-ups for [PR #9](https://github.com/jdomingo117/fin-app/pull/9). Classic remains the first-load appearance. Console rollout and the physical M1 Air smoothness check remain separate owner decisions.

## Fixture capture header

- Branch `codex/console-phase-5-owner-fixes`, based on `main` at `e6b9b4d`. The first table records the original source revisions. The after gallery was recaptured for the follow-up with the accumulated fixes. The before gallery preserves the original review evidence.
- Browser and origin are Playwright WebKit at `http://127.0.0.1:5320`. The refreshed captures use `en-AU` and `Australia/Sydney`. Each browser context stubs Auth, reports and Edge Function replies with fictional data. The fixture intercepts application requests before they reach a Supabase listener.
- Capture command from `app/`. Set `side` to `before` or `after` and pass the test name with `--grep` for an individual issue. Use the corresponding source revision and the regression from the fix commit when reproducing a before capture.

```sh
CONSOLE_OWNER_CAPTURE_DIR="../docs/design/captures/console-phase-5-owner-fixes/$side" \
  npx playwright test --config playwright.console.config.ts console-owner-fixes \
  --project=Desktop --project=WebKit
```

## Verification

Each new regression was run on the before state and against the fix in Chromium and WebKit. The particle regression also samples real pixels from the browser compositor where a fixture sprite crosses a protected figure. The normal figure contrast check keeps the live particle layer enabled.

The expanded casing audit also checks the existing Budget and Settings screens. Budget’s commitments label now uses sentence case. Settings marks the literal deletion confirmation word as keyboard input.

The initial four-shard qualification took 13m 03s on shard 2. The workflow now uses five shards and spreads the cross-screen qualification cases across all five. The signed-figure pixel test also checks the investment return inside the Accounts hub. The audio regression starts recording on the trusted click so a queued click cannot consume the recording window.
