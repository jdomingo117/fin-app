# Console Phase 5 · Owner Safari review

Use Safari on your 2020 M1 MacBook Air and your normal Halcyon account. Open the verified build and URL from the Phase 5 gate note. In the local review setup, open [Dashboard](http://127.0.0.1:5320/dashboard) and select **Console**. Start at 100% zoom and use the keyboard and trackpad as you normally would. Selecting the appearance or enabling the start screen changes a browser preference.

Read and browse throughout. Open menus, filters and details, then close them. Leave financial records, plans, account settings and imports as you found them. Skip sync, scan, upload, import, confirm, apply and save actions. If a state has no real example, record “not observed” and move on. Keep screenshots with personal figures and names on the Mac. A redacted note with the screen, action and symptom is enough.

| Done | Screen | Read-only walkthrough |
| --- | --- | --- |
| ☐ | Start | If you want to check it, enable **Show start screen** in Settings and reload Home. Wait for the wordmark to settle, then press Enter. Confirm the Overview tile has a visible rounded ring. Open a hub directly in a new tab and look for immediate entry. |
| ☐ | Home | Use the arrow keys from Overview to Budget, then return. Read the headline and its dates, move through the activity row, and check labels for long merchant names and long account names. Open a hub and verify Home returns focus to the tile you used. |
| ☐ | Overview | Scroll until the header compacts. Read net worth, movement, allocation and recent activity. Open chart values and check the date/account controls are clearly scoped to spending insights. Check the message where history or holdings are missing. |
| ☐ | Accounts | Browse short and long account names, an account with little history and any unusual account type. Check balance, balance history and activity. Open a transaction detail and close it without saving. Check that the originating control regains focus. |
| ☐ | Income | Apply a view-only date filter and inspect a sparse period. Read the source and deposit modules, including a missing source if present. Open Projections and inspect any unavailable or insufficient-history message. |
| ☐ | Expenses | Compare a typical period with a quiet one. Check long category and merchant text in the changes, category flow and transactions modules. Open the recurring view and check its empty state if applicable. Escape should close an open filter before returning from the hub. |
| ☐ | Budget | Read the current period and any historical period available through navigation. Check the spending estimate, fixed bills and funding summary. If the estimate is missing, record the exact reason shown and whether it explains what is missing. Leave the plan and any existing draft in place. |
| ☐ | Ledger | Compare **Never categorised** and **All uncategorised** with the rows and Review counts. Find an uncategorised row with a recorded category source and one with no source record. Check a long merchant name in the table and detail sheet. Escape from the sheet and verify the focus return. |
| ☐ | Ingestion | Read the steps and open the account selector without staging a file. Look for wrapping on long accounts and clear instructions when an account or file is missing. |
| ☐ | Transfers | Read the suggested pairs and unmatched queues. If a group exists, expand it and inspect long descriptions, dates and actions. If the queue is empty, check that its cleared state and any available scan are clear. |
| ☐ | Control Centre | Use the top-bar button and the C shortcut, then Tab and Shift–Tab through the sheet. Inspect attention cards with real counts and any missing or disconnected status. Close with Escape and check focus returns to the opener. |
| ☐ | Settings | Read the Effects tier and Sound rows. Check that the state of the top-bar speaker is understandable and that the sound, music and volume rows are the same size. Check keyboard focus on one switch, the tier selector and the volume slider. |
| ☐ | Zoom and motion | Repeat Home, one financial hub, Control Centre and Settings at 200% Safari zoom. Look for clipped labels or controls, inaccessible scroll areas and obscured focus rings. If you use macOS Reduce Motion, repeat Home to a hub and back with it active. Switch to another Safari tab for a few seconds, then return and check for a jump, replay or stale colour change. Restore the browser zoom when finished. |

For each issue, record **screen and route**, **action**, **what you observed**, **what you expected** and **impact**. Note the Safari version, zoom, effective effects tier and whether the problem depends on the data. Use “blocks review”, “can continue” or “cosmetic” for impact. For the gate, report whether your everyday review tasks worked and whether the Ledger labels made sense. The default switch and removal have a separate approval decision.
